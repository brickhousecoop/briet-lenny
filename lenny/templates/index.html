About This Demo

This is a demonstration deployment of Lenny, an open source lending system by Archive Labs. It simulates the OAuth login flow that a partner library would use to authenticate their patrons for ebook lending.

In production, the "Login via Partner Library" button would redirect to the partner library's real authentication system. For this demo, any credentials are accepted.
